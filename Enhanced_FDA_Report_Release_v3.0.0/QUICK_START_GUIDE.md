## 📋 Troubleshooting

### **Common Issues**

**Problem**: "Python is not recognized"
**Solution**: Install Python from https://python.org and ensure "Add to PATH" is checked

**Problem**: "pip install failed"
**Solution**: Check internet connection, or run: `python -m pip install --upgrade pip`

**Problem**: "Module not found errors"
**Solution**: Run `install_requirements.bat` again

**Problem**: "Permission denied"
**Solution**: Run command prompt as Administrator
