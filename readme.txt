General Parasoft Report Viewer - Version 2.0.0
================================================

OVERVIEW:
This application generates comprehensive static analysis reports from Parasoft C/C++test results.
It has been generalized for use by any organization or project, removing specific regulatory references.

REQUIREMENTS:
- Python 3.8 or higher
- Visual Studio 2022 (for development)
- Required Python packages: lxml, matplotlib, pillow, beautifulsoup4, requests

QUICK START:
1. Open General_Parasoft_Report.sln in Visual Studio 2022
2. Ensure Python environment is properly configured
3. Run the application (F5 or Ctrl+F5)
4. Follow the GUI prompts to generate reports

FILES INCLUDED:
- General_Parasoft_Report.py - Main application
- General_Parasoft_Report.pyproj - Visual Studio Python project
- General_Parasoft_Report.sln - Visual Studio solution
- README.md - Detailed documentation
